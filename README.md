# 困りごと制度ガイド・そよぎ (Web版)

困りごとから、使える可能性のある日本の福祉・医療・社会保障の制度を探せる情報ガイド。
An information guide for finding public support programs in Japan by the problem at hand.

- 81制度・全件に公式一次情報の出典と確認日つき / 日本語・英語
- 無料・広告なし・登録なし・端末内完結(設定のみローカル保存)
- 本体(正本): private repo `seido_guide` から `node _sync_web.js` で同期生成
- 提供: 介護と支援の相談どころ「そよぎ」 https://soudansoyogi.com/
